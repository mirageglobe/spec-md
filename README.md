# spec-md

[![License: MIT](https://img.shields.io/badge/license-MIT-yellow.svg)](LICENSE)

a standard for technical project specifications — the blueprint every codebase needs.

---

## what is spec-md?

spec-md is a structured markdown format for the `SPEC.md` file. it defines a common schema for architecture documents, design decisions, roadmaps, and complexity scoring — so developers and AI agents can navigate any project with the same mental model.

think of it like `agents.md` for agent behavior, or `.editorconfig` for code style — but for project architecture documentation.

---

## why

most projects either have no technical spec, or have one buried in a wiki that goes stale. spec-md is:

- **file-first**: lives in the repo, versioned with the code.
- **agent-readable**: structured sections and explicit tags make it easy for LLMs to scope work.
- **human-readable**: plain markdown, no tooling required.
- **opinionated but minimal**: defines what goes where, not how much to write.

---
